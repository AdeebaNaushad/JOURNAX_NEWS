# Journax-News

Journax-News is a static, frontend-only news website designed as a showcase of modern web design and layout principles. This project focuses on creating a clean, responsive, and visually appealing user interface using only HTML and CSS.

> **Note:** This project is created for demonstration purposes only and does not include backend functionality, live news updates, or interactive features.

---

## 🚀 Features

- Responsive news website layout
- Modern and clean UI design
- Multiple news sections/categories
- Mobile-friendly interface
- Fully static frontend project

---

## 🛠️ Tech Stack

- **HTML5** – For structuring the website
- **CSS3** – For styling and responsive design
